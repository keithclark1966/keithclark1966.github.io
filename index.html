01

The mission

The Color Computer 3 was never held back by its hardware. Its GIME graphics chip, the HD6309 processor and a real multitasking operating system in NitrOS-9 were ahead of what most home computers of its day were doing — what it never got was software written to that standard. That is the gap this project exists to close.

“My overall project here is to bring the true power of the CoCo 3 out to the community and the software where it should have been back in its heyday. It would have taken over Commodore and Atari computers I think. Or at least I'm going to try to do it that way.”— Keith Clark, on the project

Everything here is written from scratch, today, with modern tools — and built for the machine at its best: the full 2 MB of RAM, the HD6309, a Multi-Pak Interface and Orch-90 sound. In 1987 that stack cost a fortune and most owners never touched it; today an emulator hands it to everyone for free, so these programs build for the CoCo 3 at its maximum, no apologies.

And it is built the way community software should be: in the open, with original code, honest screenshots and honest status labels — what is released is released, what is still on the bench says so. When a program is ready, it will simply be given away to the community that has kept this machine alive for forty years.

“We're going to use every capability of this little baby.”— Keith, setting the design rule for everything built here

02

The complete CoCo 3

The projects below are not a scattered hobby list — they are one build, with one destination: a complete CoCo 3 with all available software and our own programs. One machine, assembled in the open: the whole preserved library of CoCo software, and a new suite of programs written for it today, living together behind one desktop.

“A complete CoCo 3 with all available software and our own programs.”— Keith Clark, naming the project's goal, 4 November 2026

The foundation is NitrOS-9 EOU, the community's modern OS-9 distribution. On it sits Prism, the graphical desktop — the machine's face. Around Prism grows a suite of home-grown programs, all written here: the System Monitor, an Orchestra-90 music player and ongoing PSG sound work through the Multi-Pak — one family of software, built as one machine's own.

The library is the Color Computer Archive's — four decades of CoCo software, preserved by the community. Their work, not ours, and credited as such. A local copy of their SDC card image is now in hand and verified (4 November 2026: 5,367 files, 5,282 disk images). The next major piece, the Librarian, will index that library so the whole collection can be browsed, searched and launched from inside Prism — a few keystrokes away, inside the machine.

The projects

One flagship, out the door — and the bench behind it. Each project gets its own page as it matures; statuses are kept honest.

Prism

Released · v0.2.1

A Finder-style graphical shell for the CoCo 3 under NitrOS-9 EOU: a menu bar, drive icons, draggable windows and double-click program launching — the desktop the machine always deserved. Written from scratch in C, and free and open source (MIT). Version 0.2.1 is public now; newer builds are in verification.

System Monitor

In development

A utility in the Prism ecosystem that shows what the machine is doing: processes, memory — with the map of the GIME's 8K blocks — CPU load, drive space and uptime.
