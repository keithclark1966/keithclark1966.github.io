# Modern CoCo 3 Software — master site

The front-door page for Keith Clark's modern Color Computer 3 software
projects. It introduces each project — Prism (the flagship graphical shell),
System Monitor, the Orch-90 Demo, and the CoCo RTS in design — with an honest
status label on each, and links out to each project's own page.

## Files

- `index.html` — the whole page. Self-contained: all CSS inline, zero
  external resources; images are local files under `assets/` (real Prism
  screenshots). Outbound links only.
- `assets/` — screenshots copied from the Prism site.
- `preview/` — rendered previews of the finished page (desktop and phone
  widths), made with headless Firefox on Keith's desktop.
